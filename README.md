# Sehpyr
Voice powered spellcasting mod for Minecraft.

### Building Rust code
1. Install [Docker](https://www.docker.com/get-started/)
2. Run `gradlew sepple:buildDockerImages` (only has to be done once)
3. Run `gradlew sepple:buildRustNatives`
